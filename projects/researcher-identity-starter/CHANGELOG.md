# Changelog

## 0.1.0 — 2026-09-22

Initial public starter release.

### Added

- zero-dependency responsive `index.html`
- researcher identity JSON example
- Schema.org Person JSON-LD example
- publication search and copy actions
- preview SVG
- ScholarlyArticle example
- Book example
- Dataset example
- publishing checklist
- standalone repository / GitHub Pages setup guide
- contributing guide
- MIT license
- CITATION.cff metadata

### Design principles

- one canonical Person `@id`
- public profile URLs in `sameAs`
- ORCID / ISNI as Person identifiers
- DOI / ISBN attached to works
- no inferred memberships or affiliations

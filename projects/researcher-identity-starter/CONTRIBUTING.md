# Contributing

Small, practical improvements are welcome.

Good contributions include:

- accessibility improvements
- more robust copy/search behavior
- additional Schema.org work examples
- clearer identity/identifier documentation
- validation helpers
- responsive UI fixes
- examples for public researcher profiles

Please avoid:

- scraping private or restricted profiles
- adding unverified personal data
- treating a profile as proof of organizational membership
- placing DOI/ISBN values on a Person entity

When adding a new structured-data example, reference the shared canonical Person with `@id` instead of duplicating the Person object.
